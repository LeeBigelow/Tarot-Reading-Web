# HTML stub files
`layout-LAYOUT_NAME.html` files will be sourced by the `tools/make-js-layouts.sh` script to make the `layout-LAYOUT_NAME.js` files for the main `index.html`.

Needs to include a `<h1>LAYOUT_TITLE</h1>` line.

Keep only one `class="card"` on a line so the script can count the number of cards needed for the layout properly.
